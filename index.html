YT_CDS

A private YouTube publishing tool for a single channel.

What it does

YT_CDS uploads finished, already-approved videos to the operator's own YouTube channel and schedules them for publication. It uses the YouTube Data API to upload a video, set its title, description, thumbnail, playlist and publish time, and check its processing status.

It is run by one person for their own channel. It is not offered to the public, and there is no sign-up.
