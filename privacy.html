YT_CDS Privacy Policy

Effective date: November 7, 2026

YT_CDS is a private tool that one operator uses to publish videos to their own YouTube channel. It is not offered to the public. This policy explains how it handles data obtained through Google and YouTube APIs.

Data accessed

With the operator's authorization, YT_CDS uses YouTube API Services to:

  • upload videos and set their title, description, tags, thumbnail, playlist, privacy status and publish time;
  • read the channel ID and the upload list of the authorized channel;
  • read the upload, processing and privacy status of videos it uploaded.

It does not access viewers' personal data, comments, or analytics.

How data is used

This data is used only to publish the operator's videos and to confirm that publishing succeeded. It is not sold, not used for advertising, and not used to train AI models.

Storage

The OAuth refresh token is stored in a permission-restricted file on computers controlled by the operator. Video metadata, YouTube video IDs and job status are stored in a local database on those computers.

Sharing

Data is shared only with Google, as needed to call YouTube API Services, and with Telegram, which delivers status alerts to the operator. Alerts may include a video's title and publishing status. OAuth tokens are never included.

Retention and deletion

Job records are kept while they are needed to operate and audit publishing. The operator can delete them at any time. Removing access revokes the token; the stored copy is then deleted by the operator.

Access can be revoked at any time from the Google security settings page.

Google and YouTube terms

YT_CDS uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Changes

Changes to this policy are published on this page with a new effective date.
